# Lobe Chat

[Lobe Chat](https://github.com/lobehub/lobe-chat) 是一个开源的、采用现代设计的 ChatGPT/LLMs UI/框架。

支持语音合成、多模态和可扩展（函数调用）插件系统。

一键免费部署您的私有 OpenAI ChatGPT/Claude/Gemini/Groq/Ollama 聊天应用程序。

它支持 vLLM 作为 AI 模型提供商，以高效地服务大型语言模型。

有关详细信息，请参阅教程 [在 LobeChat 中使用 vLLM](https://lobehub.com/docs/usage/providers/vllm)。
